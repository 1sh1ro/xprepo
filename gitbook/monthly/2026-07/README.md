# 2026 年 7 月二级市场月报

7 月市场呈现核心资产修复：总市值上升且 BTC 主导率同步提高，修复仍偏向核心资产。本月更值得关注的不是单一价格涨跌，而是资金集中度、杠杆温度与情绪确认之间的错位。

## Key Takeaways
- 市场状态为核心资产修复：总市值由 $2.04T 变为 $2.21T，月内变化 +8.45%；总市值上升且 BTC 主导率同步提高，修复仍偏向核心资产。
- 头部资产样本上涨 6 个、下跌 4 个：中位数收益 +1.63%，最强 ETH +14.84%，最弱 HYPE -17.13%。
- 月末市值集中度：Top10 外市值占比为 20.26%；该指标描述市值结构，不单独证明长尾风险偏好。
- 杠杆偏多：Deribit BTC/ETH 月内平均 8h 资金费率为 +0.40bps / +0.22bps。
- 情绪状态：恐惧与贪婪指数月末为 25（恐惧），月均约 25.3；价格上涨但情绪仍弱，情绪修复落后于价格。

## 宏观代理与市场状态
总市值月内上行 +8.45%，BTC 主导率提高 +1.14pct。这个组合通常对应“核心资产修复”而不是“全市场进攻”：资金愿意重新承担风险，但优先选择流动性最好、共识最强的资产。

## 交易所流量与资金活跃度
前排交易所历史自然月明细暂无可验证数据，因此本节不使用当前/滚动 30d 快照冒充目标月。全市场口径显示，7 月日均成交额约 $63.10B，成交峰值约 $88.27B。
这意味着本月价格修复并不是在完全低流动性环境中完成，但平台间流量迁移和执行质量仍需要在补齐交易所明细后再判断。

## 主流资产表现与市场广度
口径说明：Top10 样本按报告生成时的当前市值排名选取，再回溯目标月收益；该方法存在幸存者偏差，不代表目标月初的历史 Top10 成分。
头部资产中，表现最强的是 ETH（+14.84%），最弱的是 HYPE（-17.13%），收益差约 31.97pct。

Top10 外市值占比月末为 20.26%；它是集中度指标，不能代替更广资产收益率广度。

## 链上风险偏好
DeFi TVL 月末约 $75.31B，Ethereum 占比 54.97%，Solana 与 BSC 分别为 6.39% / 6.51%。
结构上，链上资金仍集中在 Ethereum 生态，Others 占比 21.16%；单月截面不能单独证明资金正在扩张或撤离。
NFT 月成交额约 $220.58M。当前产物缺少可比的前月同口径数值，因此只披露规模，不据此判断 NFT 风险偏好确认或落后于流动代币。

## 衍生品仓位温度
资金费率整体为正（BTC +0.40bps，ETH +0.22bps），市场仍有一定多头偏好，但尚未到极端拥挤的阶段。
DVOL 月末降至 BTC 35.64 / ETH 50.21，较月内高点 BTC 42.91 / ETH 56.89 明显回落。波动率回落与资金费率中性共存，意味着市场短期更像“修复后的再定价”，而不是高杠杆趋势行情。

## 下月交易框架（基准情景）
1. 基准情景：维持核心资产优先的选择性风险暴露。该配置只有在总市值守住修复成果、成交不收缩且杠杆没有进一步拥挤时才成立。
2. 上行情景：若市场广度扩散、成交放大且 F&G 回到中性区间以上，再逐步提高头部 alt 的风险预算。
3. 风险情景：若总市值回吐涨幅、DVOL 上冲，或 Funding 快速转正形成拥挤，应降低追涨仓位、执行止盈并提高保证金缓冲。
